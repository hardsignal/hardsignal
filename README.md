# Hardsignal Labs

Independent cyber-physical security research across embedded hardware, firmware and radio.

![Hardsignal Labs — Independent. Curious. Disciplined.](hardsignal-labs-principles.png.PNG)

## Research approach

Curiosity drives the investigation. Discipline makes the evidence trustworthy.

I investigate how physical systems behave and where their security assumptions fail, using hands-on experiments, measurements and reproducible evidence.

## Areas of investigation

- Embedded debugging and bus analysis — SWD/JTAG, UART, SPI and I²C
- Firmware extraction and analysis
- Power-trace capture, side-channel analysis and fault-injection research
- RF/SDR experimentation and direction finding
- NFC/RFID and automotive CAN security
- Instrument automation and documented test workflows
